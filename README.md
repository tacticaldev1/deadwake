# Deadwake — Inherit the Tide

A narrative pixel-art sailing game. Inherit your father's boat, run his old
delivery routes between five villages, and decide the fate of whatever he
sealed away at Ashenreach.

## Running it

```sh
npm install
npm run dev
```

Then open http://localhost:8080.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — lint the codebase
- `npm run test` — run the unit tests (vitest)

## Stack

Vite, React, TypeScript, Tailwind CSS, shadcn/ui components.
